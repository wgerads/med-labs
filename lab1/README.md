# Med

Выполнил Акулов Евгений Николаевич, ПИЭ-42

## Название

Med — информационная система учёта пациентов стационара больницы.

## Определение предметной области

Больница принимает пациентов на стационарное лечение. Пациенты размещаются в палатах, в каждой палате
ограниченное количество коек. При поступлении регистратор заносит пациента в систему, находит палату
со свободными койками и открывает на пациента медицинскую карту: в ней указываются лечащий врач, палата
и дата поступления. Одна медицинская карта соответствует одной госпитализации, поэтому у пациента их может быть несколько.
Во время лечения врач ставит диагноз по классификатору МКБ и назначает пациенту медикаменты, указывая частоту
и длительность приёма. При выписке врач записывает рекомендации, карта закрывается, и койка в палате освобождается.
С системой работают регистраторы и врачи.

## Бизнес-процессы

### 1. Госпитализация пациента

Участники: регистратор, пациент.

Регистратор ищет пациента в системе. Если пациент обращается впервые, регистратор заносит его данные.
Затем регистратор смотрит, в каких палатах есть свободные койки, и открывает медицинскую карту:
выбирает палату и лечащего врача, указывает дату поступления. Койка в палате считается занятой,
пока карта не закрыта.

### 2. Назначение лечения

Участники: врач.

Врач открывает медицинскую карту пациента, выбирает диагноз из списка диагнозов (с кодом МКБ) и назначает медикаменты
из общего списка, для каждого указывая частоту и длительность приёма. Если лечение нужно изменить,
врач отменяет назначение.

### 3. Выписка пациента

Участники: врач.

Врач записывает в медицинскую карту рекомендации и закрывает её датой выписки. Койка в палате освобождается.
Закрытая карта остаётся в системе как история лечения пациента.

## Требования к системе

1. Регистрация пациента и просмотр списка пациентов.
2. Просмотр пациента вместе с его медицинскими картами.
3. Просмотр палат с количеством свободных коек.
4. Открытие медицинской карты с указанием палаты и врача.
5. Просмотр медицинской карты вместе с диагнозом и назначениями.
6. Указание диагноза и закрытие медицинской карты.
7. Назначение медикамента и отмена назначения.

## Таблицы базы данных

| Таблица | Поля |
|---|---|
| Пациент | id, ФИО, дата рождения, телефон, полис |
| Врач | id, ФИО, специальность |
| Палата | id, номер, количество коек |
| Диагноз | id, название, код МКБ |
| Медицинская карта | id, пациент, врач, палата, диагноз, дата открытия, дата закрытия, рекомендации |
| Медикамент | id, название, лекарственная форма |
| Назначение | id, медицинская карта, медикамент, частота приёма, длительность приёма |

Связи:

- у пациента много медицинских карт, карта принадлежит одному пациенту;
- врач ведёт много медицинских карт, у карты один лечащий врач;
- в палате лежит много пациентов (много открытых карт), карта относится к одной палате;
- диагноз встречается во многих картах, у карты один диагноз (до осмотра врача он не указан);
- в карте много назначений, назначение относится к одной карте;
- медикамент встречается во многих назначениях, в назначении один медикамент.

Правила:

- карта открыта, пока у неё не указана дата закрытия;
- свободные койки в палате = количество коек − количество открытых карт в этой палате;
- открыть карту можно только в палате, где есть свободная койка.
